你从医院回到家，手里拿着一张装有检查影像的光盘。你把它塞进电脑，然后……什么动静都没有。也许弹出一个窗口又卡住了。也许它让你装个什么东西，可怎么都装不上。也许你用的是 Mac，光盘插进去好像完全没反应。

先别急，深呼吸。这是人们最常遇到的烦心事之一，而好消息是：你真正的影像几乎肯定没问题。出问题的，通常是光盘里附带的那个小小的看片程序，而不是影像本身。我们来一步一步、心平气和地把你的影像找出来。

## 光盘上其实有两样不同的东西

这一点医院从来没人跟你解释过。一张影像光盘几乎总是装着两样分开的东西：

1. **一个看片程序**，光盘会试图自动启动它。这就是你插入光盘时打开（或试图打开）的那个小应用。
2. **你真正的医学影像**，以一种叫 DICOM 的格式存成标准文件。

看片程序和影像是分开的。当你的光盘"打不开"时，几乎总是那个*看片程序*出了问题，而不是你的影像。也许那个看片程序只为 Windows 而做，而你用的是 Mac。也许它太旧了、或损坏了，又或者被你电脑的安全设置拦住了。

让人松一口气的是：你根本不需要那个看片程序。你的影像是标准文件，许多免费的现代程序都能直接打开它们。

## 第一步：看看光盘上到底有什么

我们不让光盘运行它自己的程序，而是像打开普通文件夹那样打开它，看看里面。

- **在 Mac 上：** 插入光盘。桌面上、或 Finder 窗口左侧应该会出现一个光盘的图标。双击那个图标去看里面的文件，而不要去运行任何弹出来的程序。
- **在 Windows 上：** 插入光盘。如果弹出窗口问你想做什么，选择"打开文件夹以查看文件"。如果什么都没出现，打开**文件资源管理器**，然后点击左侧的光盘驱动器（通常标着 D: 或 E:）。

现在看看文件名。你要找的是两样东西：

- 一个叫 **DICOMDIR** 的文件（没有扩展名）。它就像你所有影像的一份目录。
- 一个文件夹，常叫 **DICOM** 或 **IMAGES**，里面满是名字形如 `IM_0001`、或者一串没有熟悉扩展名的数字的文件。

如果你看到了这些，恭喜你。你的影像就在那里，完好无损。光盘上那个坏掉的看片程序，从来都不是真正的障碍。

## 常见问题

**打开这些文件安全吗？**
安全。你光盘上的影像文件是标准的医学影像文件。用免费看片软件打开它们，只是把图像显示出来，和你医生看到的是同一批。常常惹麻烦的，是光盘上附带的那个小程序，而不是影像本身。用一款可信赖的免费看片软件直接打开文件，是一种安全且常见的做法。和往常一样，任何看片软件都请从它的官网下载。

**为什么我的医院光盘在 Mac 上打不开？**
通常是因为光盘里内置的那个看片程序只为 Windows 而做，所以 Mac 运行不了。你的影像仍然在那里，是标准格式。只要把光盘当作文件夹打开，再用一款 Mac 能用的看片软件（比如 Weasis 或 Horos）直接打开它们就行。

**什么是 DICOM？DICOMDIR 文件又是什么？**
DICOM 是全世界通用的医学影像标准格式。DICOMDIR 文件是一种目录，列出你光盘上所有的影像，好让看片软件按顺序加载它们。让你的看片软件去指向 DICOMDIR，往往是一次性打开全部影像最省事的办法。
